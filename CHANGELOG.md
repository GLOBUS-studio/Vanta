# Changelog

## 0.1.0

Initial VantaJS2 foundation.

- New renderer-agnostic core: lifecycle, scheduler, input, visibility, adaptive
  quality, context-loss handling, fallback, typed events.
- `@vantajs2/three` adapter: WebGL2 renderer, fullscreen pass, deep disposal.
- Clean-room effects: `waves`, `aurora`, `net`.
- Docs app with live configurator and effect switching.
- Unit tests, Playwright smoke tests, size budgets, and CI.
- Legacy Vanta 0.5.24 archived in `legacy/` for reference and attribution.
