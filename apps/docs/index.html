Runtime

Performance is a feature,
not a footnote.

The core is renderer-agnostic. three.js is a peer dependency, not a hidden bundle tax. The runtime owns time, size, input, and quality.

∿

One RAF loop

All instances share a single scheduler. No competing animation loops, no duplicated bookkeeping.

◐

Adaptive quality

Sustained low frame rates lower the DPR multiplier automatically. A single hitch never triggers a downgrade.

⌁

Visibility aware

IntersectionObserver and visibilitychange stop the loop when nothing is visible. Battery is not a suggestion.

⌀

Deep teardown

Geometry, materials, textures, render targets, listeners, observers, and canvas are released on destroy.

◇

SSR-safe imports

No window access at module scope. Import the effect in a server component; create it on the client.

✦

Clean-room effects

Original shaders and algorithms. No copied Shadertoy code, no p5 runtime, no license surprises.

mount.ts 
import { createEffect } from '@vantajs2/core'
import { waves } from '@vantajs2/effects/waves'

const effect = createEffect(waves, {
  el: '#hero',
  color: '#072438',
  highlightColor: '#63e6ff',
  speed: 1,
})

await effect.ready
effect.setOptions({ waveHeight: 2.2 })
effect.pause()
effect.resume()
effect.destroy()
effect.ready

A promise. It resolves after the first frame, including the fallback path.

effect.stats

Live FPS, frame time, DPR, quality, frame count, visibility, and pause state.

effect.on()

Typed events: ready, resize, pause, resume, error, contextlost, contextrestored, qualitychange, destroy.

effect.destroy()

Idempotent. Removes the canvas, restores container styles, and disposes GPU resources.
